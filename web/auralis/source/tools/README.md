# Ferramentas de desenvolvimento

- training/: treinamento opcional do classificador de famílias de timbres da versão 1.1.
- reviewer/: treinamento, avaliação e documentação reproduzível do novo revisor de candidatas da versão 1.2.
- make-review-examples.mjs: regenera os MIDIs de exemplo a partir das amostras sintéticas e dos modelos incluídos. Execute na raiz do projeto com Node e FFmpeg.

Os modelos já vêm treinados. Estas ferramentas não são necessárias para usar index.html e não são executadas no navegador do usuário.
